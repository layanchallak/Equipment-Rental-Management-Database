# Equipment Rental Management Database

## 📌 Description

The objective is to design a **relational database** for managing equipment rentals within an organization. The database keeps track of equipment, categories and subcategories, individual equipment copies, employees, reservations, and equipment availability.

## 🎯 Objectives

The database is designed to manage:

* 📁 Equipment categories and subcategories
* 💻 Different types of equipment
* 📦 Individual equipment copies
* 🔧 Equipment availability and unavailability
* 👨‍💼 Employees
* 📅 Equipment reservations
* 🔄 Borrowing and return dates
* 📊 Maximum number of loans allowed per category
